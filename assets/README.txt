Behind the Prompt — 六屏完整装饰素材包

此包包含六屏背景、原始装饰文字、纸张叠层、卡片边缘纹理、
首页 DATA 字符，以及每屏粒子字符。没有把按钮、输入框或用户照片压进背景。

安装：
1. 把 visuals.css 和 visuals.js 复制到项目文件夹，与 index.html 同一层。
2. 打开此包的 assets 文件夹，把里面所有文件复制到项目现有 assets 文件夹。
   同名文件可替换；保留其他文件。
3. 在 index.html 的 </head> 前加入：
   <link rel="stylesheet" href="./visuals.css">
   <script src="./visuals.js" defer></script>
4. 保存，在 Live Server 页面刷新。

保留已有 styles.css 和 app.js，不要删除或替换。
这些素材加载代码兼容此前提供的 app.js（.page-number / .two-column / .card）。
它只添加装饰，不改变聊天、图片处理或收据逻辑。
新增真实文字输入会使卡片高度不同于 Figma，因此仍需检查浏览器中的排版。

包含 20 个 PNG，1 个素材清单 JSON，2 个字符 TXT，以及上述 CSS/JS。
PNG 背景为纯装饰透明图，不包含完整页面截图。
六屏素材来源：Figma 工作页 79:427 中的定稿六屏。
